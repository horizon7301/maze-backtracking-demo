# 迷宫问题的动画演示 —— 回溯算法（栈）

数据结构课程实验：用回溯算法动态演示迷宫求解。

## 功能

- 设置迷宫行列（5–41）
- 四种生成方式：随机 DFS、Prim、递归分割、随机障碍
- 可选搜索方向顺序（预设 / 自定义 / 随机）
- 动画演示：前进、死路回溯、最终路径
- 支持暂停、单步、手动改墙与起终点

## 使用方法

用浏览器直接打开 `迷宫回溯动画演示.html`（无需联网）。

1. 点击「生成迷宫」
2. 点击「开始搜索」
3. 可用「暂停 / 单步执行」观察每一步

## 算法

使用显式栈实现回溯：进栈前进，出栈回溯。时间与空间复杂度均为 O(行 × 列)。

详见 `说明.md`。
