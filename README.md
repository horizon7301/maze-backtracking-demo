# 迷宫问题的动画演示 | Maze Solver Visualization

一个基于 HTML、CSS 和原生 JavaScript 开发的迷宫生成与求解可视化项目。通过动态展示深度优先搜索（DFS）与栈实现的回溯算法，将抽象的数据结构和算法执行过程转化为直观的交互式动画。

项目支持多种迷宫生成算法、自定义搜索方向、实时栈状态展示和手动编辑迷宫，可用于数据结构课程学习、算法演示与交互式可视化实践。

## ✨ 项目特性

* 多种迷宫生成算法：支持随机 DFS 回溯生成、随机 Prim 生成、递归分割生成和随机障碍生成。
* 动态回溯可视化：实时展示搜索过程中的前进、探索、回退与最终路径。
* 灵活的搜索策略：支持预设方向、自定义方向和随机方向顺序，观察不同策略对搜索过程的影响。
* 交互式动画控制：支持开始、暂停、继续、单步执行、重置和速度调节。
* 实时数据结构展示：显示栈内容、栈深度、访问格子数、回溯次数、执行步数及搜索日志。
* 伪代码同步高亮：将算法执行状态与对应伪代码关联，帮助理解回溯算法的执行逻辑。
* 迷宫手动编辑：支持通过点击或拖动修改墙壁与通路，并自定义起点和终点。
* 多路径与无解场景：支持生成环路、调整随机障碍密度，并可检测迷宫是否存在可行路径。
* 响应式布局：适配桌面端、平板和手机屏幕。

## 🧠 核心算法与数据结构

### 1. 迷宫生成

项目实现了四种迷宫生成方式：

* **Randomized DFS**：通过深度优先搜索与回溯生成迷宫，通常形成较长的走廊。
* **Randomized Prim’s Algorithm**：通过随机扩展边界房间生成迷宫，形成较多分支。
* **Recursive Division**：通过递归划分区域与设置墙壁生成迷宫。
* **Random Obstacles**：通过可调节的随机障碍密度生成迷宫，并支持连通性检测。

此外，前三种结构化迷宫支持额外打通部分墙壁，以增加环路和可行路径。

### 2. 基于栈的回溯求解

求解过程采用显式栈实现深度优先搜索，而非依赖递归调用。

核心流程：

1. 将起点压入栈，并标记为已访问。
2. 检查栈顶格子，按照指定方向顺序寻找可通行且未访问的相邻格子。
3. 找到可行格子后，将其压入栈并继续搜索。
4. 若当前格子的所有方向均无法继续，则将其弹出栈，回退到上一个位置。
5. 当到达终点时，输出栈中保存的路径；若栈为空仍未到达终点，则判定无解。

栈元素保存当前位置、下一个待尝试的方向及方向顺序，使算法能够在回退后继续探索尚未尝试的方向。

### 3. 数据结构

* **二维数组**：存储迷宫网格。
* **访问标记数组**：避免重复访问，防止在存在环路的迷宫中无限循环。
* **栈（Stack）**：保存当前搜索路径，实现前进与回溯。
* **方向数组**：表示上、右、下、左四个移动方向。
* **广度优先搜索（BFS）**：用于迷宫连通性检测及相关测试。

### 4. 复杂度分析

设迷宫共有 `n = rows × cols` 个格子。

* **时间复杂度**：`O(rows × cols)`
* **空间复杂度**：`O(rows × cols)`

由于每个格子最多入栈一次，且每次最多检查四个方向，求解过程的操作规模与迷宫格子数量成线性关系。

注意：深度优先搜索与回溯算法找到的是一条可行路径，不保证是最短路径。若需要寻找最短路径，可采用 BFS 求解。

## 🚀 如何运行

### 环境要求

* Chrome、Edge、Firefox 或 Safari 等现代浏览器。
* 无需安装 Node.js、第三方依赖或配置服务器。

### 运行步骤

1. 下载或克隆本项目仓库。
2. 找到文件 `迷宫回溯动画演示.html`。
3. 使用浏览器直接打开该文件。
4. 设置迷宫大小、生成方式和搜索方向。
5. 点击「生成迷宫」，再点击「开始搜索」观看动画。

你也可以使用「单步执行」逐步观察栈的变化、伪代码高亮和搜索日志，或者进入手动编辑模式，自行构造不同的迷宫场景。
